# 💎 DepilZone Proyect  

Chat interactivo e intuitivo en tiempo real  

Contiene usuarios, salas y mensajes privados, estados de conexión y desconexion con **React + Node.js + MongoDB + Socket.IO**.

## 🚀 Tecnologías Utilizadas

### **Frontend**
- ⚛️ [React + Vite](https://vitejs.dev/)  
- 🎨 [TailwindCSS](https://tailwindcss.com/)  
- 🔄 [Axios](https://axios-http.com/)  
- 🔐 [JWT](https://jwt.io/)  

### **Backend**
- 🟢 [Node.js + Express](https://expressjs.com/)  
- 💾 [MongoDB con Mongoose](https://mongoosejs.com/)  
- 🔌 [Socket.IO](https://socket.io/)  

### **Herramientas de Desarrollo**
- 🐙 [GitHub](https://github.com/) (control de versiones)  
- 🔑 [ESLint + Prettier](https://eslint.org/) (formato y buenas prácticas)  
- 🚀 [Render](https://render.com/) / [Vercel](https://vercel.com/) (deploy)
